---
title: Running HAEO
description: Understanding how HAEO automatically optimizes your energy system.
---

Unlike EMHASS which requires scripts and automations to trigger optimization, HAEO runs automatically. There's no need 
to create scripts, REST commands, or scheduled automations to run the optimizer.

### Automatic Optimization

HAEO automatically re-optimizes whenever any of your input sensors update:

- Price forecasts change (Amber updates prices every 5 minutes)
- Solar forecasts update (Solcast updates periodically)
- Battery state of charge changes
- Load forecast updates

This event-driven approach means your energy plan is always up-to-date with the latest information. You don't need to 
worry about scheduling optimization runs or missing price changes.

### Checking Optimization Status

You can monitor optimization through these sensors:

| Sensor | Description |
| ------ | ----------- |
| `sensor.{network}_optimization_status` | Shows `success`, `failed`, or `pending` |
| `sensor.{network}_optimization_duration` | How long the optimization took (seconds) |
| `sensor.{network}_optimization_cost` | Total forecasted cost ($) |

For a network named "Sigenergy System", these would be:
- `sensor.sigenergy_system_optimization_status`
- `sensor.sigenergy_system_optimization_duration`
- `sensor.sigenergy_system_optimization_cost`

### Manual Refresh

If you ever need to force a re-optimization:

1. Go to **Developer Tools** → **Services**
2. Call `homeassistant.update_entity` 
3. Target any HAEO sensor (e.g., `sensor.sigenergy_system_optimization_status`)

Or simply click on any HAEO sensor in the UI and use the refresh button.

### Output Sensors

HAEO creates sensors for each element you configured. These sensors contain both the current optimized value and a 
`forecast` attribute with future values across the entire optimization horizon.

**Battery sensors:**
- `sensor.battery_active_power` — current optimal power (positive = discharge, negative = charge)
- `sensor.battery_state_of_charge` — current and forecasted SOC

**Grid sensors:**
- `sensor.grid_active_power` — current optimal grid power (positive = import, negative = export)
- `number.grid_import_price` — import price with forecast
- `number.grid_export_price` — export price with forecast

**Solar sensors:**
- `sensor.solar_power` — optimal solar generation
- `number.solar_forecast` — solar forecast input

**Load sensors:**
- `sensor.load_power` — load power forecast

All sensors include a `forecast` attribute containing timestamped future values. You can inspect these in 
**Developer Tools** → **States** by clicking on any HAEO sensor.

### Performance

On typical hardware, HAEO optimization completes in 1-5 seconds. If optimization is taking too long:

- Reduce tier 4 count (fewer far-future intervals)
- Increase tier durations (coarser resolution)
- Simplify your network (fewer elements)

You can monitor performance via `sensor.{network}_optimization_duration`.
