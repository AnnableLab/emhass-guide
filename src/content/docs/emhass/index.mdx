Welcome to the EMHASS guide. This guide will walk you through setting up 
[EMHASS](https://github.com/davidusb-geek/emhass) (Energy Management for Home Assistant) to automate your Sigenergy 
battery system.

## What You'll Set Up

By following this guide, you'll configure:

1. **EMHASS addon** — The optimizer that creates your energy plan
2. **REST commands** — Communication between Home Assistant and EMHASS
3. **Scripts & automations** — Trigger optimization and apply the results
4. **Dashboard** — Visualize your energy plan with ApexCharts
5. **Battery automation** — Automatically control your Sigenergy system based on the plan

## Why EMHASS?

EMHASS is a mature, well-established project with a large community:

- **Proven solution** — Used by many in the Home Assistant community
- **Extensive documentation** — Comprehensive configuration options
- **Active development** — Continuously improved with new features
- **Standalone addon** — Runs independently from Home Assistant core

Note: EMHASS requires more manual configuration than HAEO, including YAML files and REST commands. If you prefer a 
simpler UI-based setup, consider the [HAEO guide](/haeo) instead.
